Direct kernel reference

Bypasses the entire bench framework. Calls xform.transformArray(input) in a raw tight loop — no transform() wrapper, no ctx property accesses, no batch indirection. If this matches the framework's number, the framework adds zero overhead. If it's faster, the framework is the source of the gap vs. the old bench.

Direct kernel: minimal inline loop, no framework abstractions. Reads what the kernel can do with zero overhead around it.
Self-contained scenario: one function file that owns its own setup, warmup, hot loop and timing — the “production code shape” pattern. V8 sees it as one independent compilation unit, so the call site to xform.transformArray stays monomorphic and inlineable.
If both these match but the registered wasm-simd benchmark above is slower, the registered framework’s shared call site is the source of the gap.
